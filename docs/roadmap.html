GeoLock · ScaleLock · build plan v3 · 24 Oct 2026

From empty repo to BMVC 2027

33 small steps in six phases, in one shared Python 3.11 environment, with every matcher and dataset run from its official code. Geometry is built and tested on synthetic scenes first. A first real localization on GTA-UAV decides go or no-go. The heavier extras (DEM orthorectification, PnP, caching, uncertainty) are built only right before the experiment that needs them.

Timeline

To scale, 26 Oct 2026 to late May 2027. Hatched bars are optional.

Steps by phase

Every step ends with a passing test. Steps 01 to 17 go straight to main; from Step 18 each step gets its own branch and PR.

How we keep it simple

Plain functions

Geometry is small numpy functions. The only abstract class is Matcher.

Official code

Each matcher runs from its authors' repo (MatchAnything from their Hugging Face Space), pinned to a commit, behind one short adapter file.

Main first

Steps 01 to 17 commit to main. After the first working version, one branch and PR per step.

One pipeline

Conditions 1 to 8 are settings passed to the same run_frame(), never copies of it.

Flat result tables

One Parquet row per frame. O1 to O4 are all computed every run and compared offline.

Build late

DEM ortho, PnP, caching and uncertainty arrive just before the experiment that uses them.

Synthetic first

A renderer with known answers tests every formula before any real frame is used.

No ground truth leaks

A test sets gt_EN to NaN and checks the output is unchanged.

Full plan with files, functions and "done when" checks: docs/IMPLEMENTATION_PLAN.md in the geolock-uav repo. Maths follows the research spec v2, §5.
